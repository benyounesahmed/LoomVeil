# LoomVeil

LoomVeil is a Cloud Native Platform that enables scalable distributed architecture and auto-scaling capabilities on a robust layer.

LoomVeil is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/LoomVeil.git`
2. `cd LoomVeil`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure LoomVeil, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
